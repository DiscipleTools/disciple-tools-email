# Disciple.Tools - D.T Email (Deprecated)

> **This plugin is deprecated and no longer maintained.** Sending email to records is part of the Disciple.Tools theme as of version 1.58.0. Deactivate and delete this plugin.

In the theme, open a list (for example Contacts), choose **Bulk Send Message**, select one or more records and send. Since theme 1.69.1 each sent email is also saved as a comment on the record. The Mailgun features of this plugin (receiving replies into record comments and forwarding to a list) have no replacement in the theme.

This plugin was never published as a release, so no site receives updates from this repository.
